# Claude Code Instructions

Leia `AGENTS.md` antes de iniciar qualquer tarefa; ele é a fonte de verdade (contexto, regras, fluxo OpenSpec, comandos, execução via Task Manager, incluindo as pendências herdadas do fork tdb-mix-blog).

Específico do Claude Code:

- Use plan mode para tarefas complexas ou que toquem múltiplos domínios antes de editar.
- Comandos OpenSpec aqui são `/opsx:*` (`.claude/commands/opsx/`), diferente de `/opsx-*` usado por Cursor/OpenCode.
- Ao final, relate: arquivos alterados, comandos executados, e testes que não puderam ser executados (com o motivo).
